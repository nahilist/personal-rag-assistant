# Personal RAG Assistant

A private full-stack document assistant with source-backed answers.

## Stack
Next.js, FastAPI, Supabase, pgvector, Celery, Redis and a configurable LLM.

## Setup
1. Copy .env.example and configure non-production credentials.
2. Install locked dependencies and run database migrations.
3. Start development services using the documented Compose profiles.
4. Start the configured embedding/model services or provide API credentials.
5. Create two test users and run the isolation smoke tests.

## Documentation
See docs/ for product scope, architecture, APIs, security and operations.
